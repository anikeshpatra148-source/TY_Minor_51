# ODI Batting Performance Analysis

This project analyzes a cricket dataset of top ODI batters and builds a simple linear regression model to predict total runs based on matches played.

## Files
- `main.ipynb` – Jupyter notebook containing the analysis, data cleaning, EDA, and regression model
- `odb.csv` – dataset used for the project

## What the notebook includes
- Dataset loading and inspection
- Data cleaning and missing value handling
- Exploratory Data Analysis (EDA)
- Correlation and visualization of batting statistics
- Simple linear regression model
- Model evaluation using MAE, RMSE, and R²

## Requirements
Install the following Python packages if needed:

```bash
pip install pandas numpy matplotlib scikit-learn
```

## How to run
1. Open the notebook in Jupyter or VS Code.
2. Run all cells in `main.ipynb`.
3. Review the EDA and regression results.

## Project goal
Predict a batter's total runs using the number of matches played as a simple linear model.
